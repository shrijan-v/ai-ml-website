# Data Analysis & AI/ML Website

A responsive, professionally styled website about **Data Analysis** and **Artificial Intelligence / Machine Learning**, built with pure HTML5 and CSS3 as part of the GitHub Intern Programme — Task 01. Hosted live on GitHub Pages.

---

## 🌐 Live Site

> **[https://shrijan-v.github.io/ai-ml-website](https://shrijan-v.github.io/ai-ml-website)**
>
---

## ✨ Features

- **Sticky navigation bar** with smooth scroll and active-link highlighting
- **Hero section** with animated floating cards and call-to-action buttons
- **About AI/ML section** — covers What is AI, What is ML, Applications, and Future Scope
- **Data Analysis section** — covers definition, importance, real-world applications, and a 5-step process strip
- **Image gallery** — showcases 3 relevant images in styled cards
- **Tools & Technologies strip** — Python, TensorFlow, Pandas, Tableau, and more
- **Contact section** — name, email, and GitHub profile
- **Responsive design** — fully mobile-friendly with a hamburger menu
- **Dark tech theme** — modern color palette with gradient accents

## 🚀 GitHub Pages Deployment

1. Go to your repository on **github.com**
2. Click the **Settings** tab
3. In the left sidebar, click **Pages**
4. Under **Branch**, select `main` and keep the folder as `/ (root)`
5. Click **Save**
6. Wait 1–2 minutes — GitHub will display a green banner with your live URL:

```
https://shrijan-v.github.io/ai-ml-website
```

7. Copy the URL, paste it into this README (Live Site section above), and push:

```bash
git add README.md
git commit -m "docs: add live GitHub Pages link to README"
git push origin main
```

> **Tip:** Also add the live link to your repo's **About** section (gear icon ⚙️ → Website field).
